# OpenMaintainer

An AI-powered GitHub maintenance assistant for open-source projects.

## What it does

OpenMaintainer helps maintainers with routine GitHub maintenance tasks:

- Summarize and triage GitHub Issues
- Summarize Pull Requests and suggest review points
- Draft release notes from merged changes
- Identify missing information in bug reports
- Provide security-aware automation with human approval

## Design goals

- Human-in-the-loop: no automatic merging or closing of issues
- Least-privilege GitHub permissions
- Treat repository content, issues, and comments as untrusted input
- Protect API keys and other secrets
- Keep automation transparent and auditablei
